## 📚 محتوى الدليل

- 📋 **مرجع سريع** — جدول مقارنة لكل الاختبارات الإحصائية
- 🔬 **دليل SPSS** — خطوات تفصيلية وقراءة النتائج لكل تحليل
- 🧠 **المفاهيم الأساسية** — الفرضية الصفرية، Sig، R²، η²، وغيرها
- ✅ **أسئلة مراجعة** — تفاعلية بإجابات مفصّلة

## 🔬 التحليلات المغطاة

### تحليلات TMA1
- الإحصاء الوصفي + الرسوم البيانية
- ت للعينة الواحدة
- ت للمجموعات المستقلة (مع Levene)
- معامل ارتباط بيرسون

### تحليلات TMA2
- ت للعينات المرتبطة (قبلي/بعدي)
- تحليل التباين الأحادي ANOVA (3 شُعب)
- اختبار Tukey للمقارنات البعدية
- الانحدار الخطي البسيط

### تحليلات مشتركة
- ألفا كرونباخ (الثبات)
- اختبارات الطبيعية (K-S / Shapiro-Wilk)
- مربع كاي
