## 📚 محتوى الدليل (6 تبويبات)

- 📋 **مرجع سريع** — بطاقات تصفية لكل أداة حسب النوع
- 🗓️ **التسلسل الزمني** — 3 مراحل · 13 أداة بترتيبها (1–13) + ANCOVA كإثرائي
- 🔬 **دليل SPSS** — شريط فرعي مقسّم بالمراحل + أزرار مرقّمة لكل أداة
- 🧠 **المفاهيم** — 10 مفاهيم أساسية + قاعدة الذهب
- 📘 **شروحات** — 4 شروحات موسّعة + أسئلة وأجوبة تفصيلية لكل اختبار (7 بطاقات)
- ✅ **مراجعة** — 12 سؤال وجواب تفاعلية + نصيحة الامتحان

## 🕐 التقسيم الثلاثي للأدوات (1–13)

### 🔵 المرحلة الأولى — التحليل الوصفي والتحقق من البيانات (الأسابيع 2–3)
1. التكرارات والإحصاء الوصفي (Frequencies)
2. التوزيع الطبيعي (Normality)
3. معامل الثبات — ألفا كرونباخ
4. **تجانس التباين — Levene** (جديد)
5. معامل الارتباط (Pearson/Spearman)
6. مربع كاي (Chi-Square)

### 🟡 المرحلة الثانية — اختبار الفرضيات والمقارنة بين المتوسطات (الأسابيع 4–11)
7. ت للعينة الواحدة
8. ت للمجموعات المستقلة
9. ت للعينات المرتبطة
10. تحليل التباين الأحادي (One-Way ANOVA)
11. **تحليل التباين الثنائي (Two-Way ANOVA)** (جديد)
12. **التحليل البعدي — Post Hoc (Tukey/Scheffé)** (جديد)

### 🟢 المرحلة الثالثة — أدوات التنبؤ (الأسبوع 12)
13. الانحدار الخطي البسيط

### 🟣 إثرائي (خارج التسلسل الرسمي)
- **+** تحليل التباين المصاحب — ANCOVA
