## 📚 محتوى الملخص (5 تبويبات)

- 🕐 **التسلسل الزمني** — أدوات التحليل الإحصائي عبر أسابيع الفصل في ثلاث مراحل
- 🔬 **دليل SPSS** — مسار القائمة + خطوات مرقّمة + سطر قراءة وتفسير لكل تحليل
- 🧠 **المفاهيم** — الإحصاء وأنواعه، تصنيف المتغيرات، الثبات، الطبيعية، حجم الأثر، ليفين
- 🧭 **قاعدة الذهب** — شجرة قرار سريعة لاختيار الاختبار المناسب
- ✅ **المراجعة** — أسئلة وأجوبة تفاعلية + نصيحة الامتحان

## 🕐 مراحل التسلسل الزمني

### المرحلة الأولى — التحليل الوصفي والتحقق من جودة البيانات (الأسابيع 2 – 3)
التكرارات · التوزيع الطبيعي · معامل الثبات (ألفا كرونباخ) · تجانس التباين · معامل الارتباط · كاي تربيع

### المرحلة الثانية — اختبار الفرضيات والمقارنة بين المتوسطات (الأسابيع 4 – 11)
ت للعينة الواحدة · ت للعينات المستقلة · ت للعينات المرتبطة · تحليل التباين الأحادي · تحليل التباين الثنائي · التحليل البعدي (Tukey / Scheffé)

### المرحلة الثالثة — أدوات التنبؤ (الأسبوع 12)
الانحدار الخطي البسيط (Simple Linear Regression)
