الدليل الشامل للتحليلات الإحصائية

خطوات SPSS · الخيارات الأساسية · قراءة النتائج · الصياغة الأكاديمية
محاضر المقرر: د. سامي المزروعي
● TMA1: وصفي + T + ارتباط ● TMA2: T + ANOVA + انحدار ● مشترك: ثبات + طبيعية
جدول مقارنة سريع لكل اختبار: متى تستخدمه، الشروط، المتغيرات، وتفسير النتيجة. صفِّ حسب نوع الاختبار من الأزرار أدناه.
يبدأ المقرر بـ وصف البيانات وتجهيزها، ثم اختبار الفروق بين المجموعات، وينتهي بـ التنبؤ بالعلاقات — ثلاث مراحل و13 أداة بترتيبها. اضغط أي أداة لعرض وصفها.
المفاهيم الأساسية التي يقوم عليها التحليل الإحصائي في المقرر.
🧭 قاعدة الذهب لاختيار الاختبار
بيانات نوعية؟ ← مربع كاي أو سبيرمان
مجموعتان مستقلتان؟ ← اختبار T المستقل
نفس المجموعة قبلي/بعدي؟ ← اختبار T المرتبط
3 شُعب أو أكثر؟ ← ANOVA + Tukey
متغيران مستقلان معاً؟ ← تحليل التباين الثنائي
ضبط متغير دخيل (قبلي)؟ ← ANCOVA
علاقة بين متغيرين كميين؟ ← ارتباط بيرسون
تنبؤ بمتغير من آخر؟ ← انحدار خطي بسيط
اتساق فقرات المقياس؟ ← ألفا كرونباخ
شروحات تفصيلية موسّعة + أسئلة وأجوبة لكل اختبار. اضغط أي بطاقة لفتح المحتوى الكامل.
